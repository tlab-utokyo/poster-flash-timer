# poster-flash-timer

ポスターフラッシュトーク用タイマー: フォルダ内の PDF を 1 件ずつ表示し、縦バー（または横バー）で残り時間を可視化する単一 HTML アプリ。

## どこで動くか

`index.html` は **GitHub Pages 上で公開しているこの URL** で動きます。インストール不要、ブラウザだけで完結します。

➡ **https://tlab-utokyo.github.io/poster-flash-timer/**

ローカルで `index.html` をダブルクリックして `file://` で開いても動作します（CDN から pdf.js を読むのでオフラインは不可）。

### 動作環境

- **推奨ブラウザ**: Chrome / Edge / Safari（最新版）
  - フォルダ選択に `webkitdirectory` を使うため、Firefox では PDF をまとめて読み込めません。
- **ネット接続**: 必須（pdf.js を CDN から読み込みます）
- **PDF を外部に送信しません**: ファイルはブラウザ内でのみ処理されます（ローカル完結）。

## 使い方

1. 上記 URL をブラウザで開く
2. 「📁 PDFが入ったフォルダを選択」で発表者ごとの PDF が入ったフォルダを指定
3. 各発表の持ち時間（既定 60 秒）を設定し「▶ 開始」

### キーボード操作

| キー | 動作 |
|---|---|
| ← → | ページ送り |
| Enter | 次の発表者へ |
| Backspace | 前の発表者へ |
| R | タイマーリセット |
| I | バー位置切替（右 / 下 / 左 / 上） |
| + / - | バーの太さ変更 |
| F | フルスクリーン |
| Esc | フルスクリーン解除 / 戻る |

### 通知音

- 残り 10 秒で「チーン」
- 持ち時間到達で「リンリン」

バー位置・太さ・持ち時間の設定は `localStorage` に保存され、次回起動時にも引き継がれます。
